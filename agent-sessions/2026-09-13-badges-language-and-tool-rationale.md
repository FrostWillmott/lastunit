# 2026-09-13 — ревизия бейджей, языковая политика, обоснование выбора инструмента

Инструмент: Claude Code (CLI). Модель: claude-opus-5 (Opus 5, контекст 1M),
эндпоинт Anthropic. Полный транскрипт —
`2026-09-13-badges-language-and-tool-rationale.jsonl` (см. `README.md` этого
каталога).

## Что сделано

- **`docs(readme): trim badges to the six that carry information`** (`58b9907`)
  — из тринадцати бейджей осталось шесть. Убраны Ruff, mypy, uv, Dependabot и
  TypeScript: это статические картинки, утверждавшие то, что README уже
  описывает в «Stack» и «Testing», а `make check` проверяет по-настоящему;
  бейдж Dependabot был вписан руками и продолжал бы говорить «enabled» после
  отключения конфига. Каждый оставленный сверен с репозиторием: `LICENSE` — MIT,
  `ci.yml` есть на этом remote, `requires-python = ">=3.12"`, compose закрепляет
  `postgres:17`.
- **`docs(readme): admit the haiku subagents were never used`** (`4e1d987`) —
  незакоммиченная работа предыдущей сессии, вынесена отдельным коммитом, чтобы
  не мешать её с ревизией бейджей.
- **`docs: settle the language policy instead of deciding per document`**
  (`72d03a5`) — всё, что может уйти заказчику, по-английски (код, сообщения
  коммитов, README, AGENTS/CLAUDE, `.claude/rules/`, DECISIONS, SECURITY);
  по-русски — адресованное проверяющему и рабочее (`docs/plan.md`, оба аудита,
  `docs/verification-*.md`). ТЗ (`docs/acceptance.md`) сохранено дословно,
  поэтому его термины цитируются непереведёнными и в английских документах.
  Записано в трёх местах с разными задачами: `DECISIONS.md` — причина и полная
  карта, `AGENTS.md` — правило там, где его читают сессии, README — пометка
  проверяющему по-русски над сгибом, с обещанием перевести любой документ по
  первому запросу и прислать вместо оригинала или отдельно.
- **`docs: say why the tool is Claude Code, not only why the models are split`**
  (`70d32b4`) — «Tools and models» объяснял разделение на три модели, но не
  выбор инструмента, и сдаточная записка прямо указывала на этот пробел.
  Причина — харнес, а не бренд: модели Anthropic исторически удобнее в работе и
  Claude Code построен вокруг них, но удерживают `.claude/rules/`, шаблон
  проекта, скиллы, определения субагентов и хуки — перенос дороже выгоды, а
  транскрипты и есть требуемый спецификацией экспорт. Там же зафиксировано, что
  второго инструмента для разделения по моделям не понадобилось:
  `ANTHROPIC_BASE_URL` направлял тот же харнес на `api.deepseek.com/anthropic`.
- **`docs: bring back the reviewer handover note as a route map`** (`ca6fe01`) —
  `docs/handover-ru.md` удалялась в начале этой же сессии и возвращена с четырьмя
  правками: п. 1 — ссылка на репозиторий без «вы уже здесь», п. 2 — снята
  оговорка о необъяснённом выборе инструмента (теперь есть абзац в README и
  запись в логе решений, обе слинкованы), п. 3 — убрано жёсткое число сессий,
  которое устаревает при каждом экспорте. Запись в `DECISIONS.md` перекрывает
  фразу «there is none in the repository at the moment» из языковой записи, а не
  правит её — лог append-only.
