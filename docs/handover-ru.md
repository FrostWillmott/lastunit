## 2. Чем делали: какая модель, какой инструмент и почему

[`README.md` → «Tools and models»](../README.md#tools-and-models). Инструмент —
Claude Code (CLI); там же, абзацем «Why Claude Code», — почему выбран он и
почему харнес вокруг него не переносится на другой инструмент. Работа намеренно
разложена на три модели в отдельных сессиях, и там же сказано зачем: ошибка
должна пережить другую модель в другой сессии, прежде чем попадёт в репозиторий.
Оба аудита нашли дефекты, которые собственное ревью исполнителя пропустило.

В логе решений: [`DECISIONS.md`](../DECISIONS.md) → «Claude Code as the tool,
and why the harness is not ported» (13.09). Одна модель работала не через
Anthropic: `ANTHROPIC_BASE_URL` направляет тот же харнес на
`api.deepseek.com/anthropic`, так что второго инструмента для этого не
понадобилось.
